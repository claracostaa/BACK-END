# JavaScript - Resumo

## História

- Criado por **Brendan Eich em 1995**.
- Passou pelos nomes **Mocha** e **LiveScript** Antes de se chamar JavaScript.
- O nome foi escolhido por estratégia do marketing, aproveitando a popularidade do Java.
- Começo como uma linguagem simples de scrips e evoluiu para uma das principais tecnologias da Web.

## Importância no Desenvolviment Web
- O JavaScript é uma das principais linguagens utilizadas no desenvolvimento Web.
- É responsável por deixar as páginas interativas e dinâmicas.
- Permite criar recursos como menus, animações, formulários, botões e validações.
- Trabalha junto com HTML e CSS:
    - HTML: estrutura da página.
    - CSS: aparência e estilo.
    - JavaScript: interação e comportamento.
- Também pode ser usado no Back-End, com tecnologias como o Node.js.
- É utilizado em sites, sistemas, aplicativos e jogos.
